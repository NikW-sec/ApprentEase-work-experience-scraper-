# ApprentEase-work-experience-scraper-

A C# scraper that collects work experience opportunities from Futures for All and UpTree and sends new listings to the ApprentEase Discord server.

The scraper runs through GitHub Actions on a weekly schedule. You can also start it manually from the **Actions** tab by selecting **auto scraping** and clicking **Run workflow**.

See the [setup notes](Resouces.md) for GitHub Actions, Discord webhooks, and GitHub secrets.
